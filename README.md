# One Word From Your Ex

One word, 14 characters: the one word an ex would actually text — entered in the [make.fun bounty](https://make.fun/c/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2).

## The entry

> newphonewhodis

14 characters, exactly one word. The whole breakup in a single beat: the ex pretending not to know you. Every judge has received this text (or sent it) — it lands instantly, no setup required.

## Run

```sh
node main.ts   # writes the entry to /output/entry.txt
```

`main.ts` writes the word to `/output/entry.txt` and enforces the gate itself: exactly one word, 1–20 characters, letters only, a single non-blank line.
